## 1. 한 줄 요약

인프런 작심삼일 챌린지를 진행하며 공부 시간 인증에 사용할 스톱워치

## 2. 왜 만드는가

- **지금은 이렇게 한다**: 다른 사람이 만든 스톱워치나 OS 기본 스톱워치를 사용한다.
- **뭐가 불편한가**: UI가 불편하거나 내가 원하는 기능을 추가하지 못해 아쉽다.

## 4. 기능 요구사항

| ID | 기능 | 우선순위 | 수용 기준 |
|---|---|---|---|
| FR-1 | 스톱워치 | MVP | 시/분/초/밀리초 가 모두 보이는 스톱워치 |
| FR-2 | 스크린샷 | MVP | 브라우저에서 보이는 스톱워치의 화면을 스크린샷으로 저장하는 기능 |
| FR-3 | PIP | MVP | 스톱워치를 PIP 모드로 전환하여 화면에 띄울 수 있는 기능 |
| FR-4 | 배경 설정 | MVP | 이미지를 첨부하면 스톱 워치 배경으로 설정 가능 |
| FR-5 | 알람 또는 알림 | MVP | 내가 원하는 만큼의 시간이 지났을 때 알람 또는 알림 기능 (브라우저) |
| FR-6 | 날짜 표출 | MVP | 오늘의 연/월/일/요일 표출 |
| FR-7 | 닉네임 설정 | MVP | 닉네임을 설정해 스톱워치를 사용 중인 사용자가 누구인지 보여주는 기능 |
| FR-8 | 달력 기능 | MVP | github streak 처럼 달력 위에 각 일별로 몇 분의 스톱워치를 실행했는지 표시 |
